# LULL — プレビュー

**https://k-aoshima.github.io/lull-preview/**

「いまの気分」や「おたより」を書くと、その人のためだけの一曲が生まれる。
ラジオDJが手紙を読み上げてから曲が流れ、通し番号が付く。同じ曲は二度と生成されない。

このリポジトリは**ビルド成果物だけ**を置いた配布用です。ソースコードと設計書は別の非公開リポジトリにあります。

## 触ってみるところ

- **お便り**タブでひとこと書いて気分を選び、「Lull を届ける」
- **波形はシークバーを兼ねています。** なぞると再生位置が動き、再生済みの範囲だけ濃くなります
- **リロードしても生成した曲は残ります**（ブラウザの localStorage）
- **ライブラリ**のサムネは曲ごとに波の形が違います。これが「一点物」の見た目での担保です
- ホーム以外のタブに移るとミニプレイヤーがせり上がります

## 注意

- **音が鳴ります。** DJ の読み上げ（端末の音声合成）のあとに曲が始まります。マイページで読み上げを切れます
- **まだ Suno API に接続していません。** 曲は Web Audio API による合成音です
- 保存先はブラウザです。端末をまたいで共有されません
